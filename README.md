# 3D ERT Karst Workflow (pyGIMLi)

Cấu trúc module:

- `mesh/`: tạo mesh 3D + dị thường karst.
- `inversion/`: thiết kế L-array, mô phỏng ERT, inversion.
- `scripts/`: entrypoint chạy toàn bộ workflow.
- `notebooks/`: notebook demo.

## Chạy nhanh

```bash
python scripts/run_3d_ert.py
```

Kết quả lưu trong `outputs/`.
